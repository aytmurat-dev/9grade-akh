## MA'LUM MUAMMOLAR

Generatsiya paytida shularni hisobga oling:

**1. Tarmoq — DNS/Web server ikki marta**
`15` (DNS va Web server) va `19` (DNS va Web server, mahalliy sayt).
19-darsni takrorlash emas, kengaytirish qilib yozing: 15-da tushuncha
va sozlash, 19-da mahalliy sayt joylash va tekshirish.

**2. Veb — API bor, JSON yo'q**
`25` (API bilan ishlash) `fetch` ni talab qiladi, u JSON qaytaradi.
Rejada JSON mavzusi yo'q. 25-dars segment xaritasida JSON tuzilishiga
alohida segment ajrating.

**3. Mobil — Activity lifecycle yo'q, Fragment bor**
`10` (Fragment) Activity lifecycle ustiga quriladi. Segment xaritasida
lifecycle uchun qisqa kirish segmenti ajrating.

**4. Veb — amaliy darslar kam (4 ta)**
26 ta nazariy darsdan keyin faqat 4 amaliy. Uy vazifalari amaliy
og'irlikda bo'lsin — har D darsida kod yozish talab qilinsin.

**5. XUI (xatolar ustida ishlash) darsi yo'q**
BSB dan keyin xatolar tahlili darsi rejada yo'q. Keyingi darsning
dastlabki 10 daqiqasi shunga ajratiladi — buni uy vazifasi
tahliliga qo'shing.
